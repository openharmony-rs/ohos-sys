## NativeDisplaySoloist native bindings for OpenHarmony

Raw FFI bindings to the OpenHarmony NativeDisplaySoloist API (available since API level 12).

C API reference: https://gitcode.com/openharmony/docs/blob/master/en/application-dev/reference/apis-arkgraphics2d/capi-nativedisplaysoloist.md

## Development

This crate is developed as part of the [ohos-sys](https://github.com/openharmony-rs/ohos-sys) bindings.
