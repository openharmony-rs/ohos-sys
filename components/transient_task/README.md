# ohos-transient-task-sys

Rust bindings for the `transient-task` module of OpenHarmony.
This crate should only be used on OpenHarmony (`target_env = "ohos"`).
The official C-API documentation is available [on gitcode][transient-task native guidelines].

[transient-task native guidelines]: https://gitcode.com/openharmony/docs/blob/master/en/application-dev/task-management/transient-task.md
