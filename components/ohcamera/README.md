## Camera native bindings for OpenHarmony

Raw FFI bindings to the OpenHarmony Camera NDK (`libohcamera.so`), available since API level 11.

C API reference: https://gitcode.com/openharmony/docs/tree/master/en/application-dev/reference/apis-camera-kit

## Development

This crate is developed as part of the [ohos-sys](https://github.com/openharmony-rs/ohos-sys) bindings.
