# Changelog

## 0.1.0

- Initial release. Bindings to `libhiappevent_ndk.z.so` for API-10 through API-26.
  Covers event writing with parameter lists (`OH_HiAppEvent_CreateParamList`,
  `OH_HiAppEvent_Add*Param`, `OH_HiAppEvent_Write`) and configuration,
  event watchers (API-12), event configs (API-15), data processors (API-18),
  `OH_HiAppEvent_SetConfigName` (API-20) and
  `OH_HiAppEvent_ReportFrameworkMemAnomaly` (API-26).
