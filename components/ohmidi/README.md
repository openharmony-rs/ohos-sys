## OH_MIDI native bindings for OpenHarmony

Raw FFI bindings to the OpenHarmony MIDI NDK (`libohmidi.so`), available since API level 24.

C API reference: https://gitcode.com/openharmony/docs/blob/master/zh-cn/application-dev/media/audio/using-ohmidi.md

## Development

This crate is developed as part of the [ohos-sys](https://github.com/openharmony-rs/ohos-sys) bindings.
